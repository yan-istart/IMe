## 2026-11-13：架构功能补全

- 新增 schema v5：`task_dependencies`、`skill_comparisons`。重启时中断的技能验证和 A/B 标为 interrupted/失败，允许重新验证。
- 依赖任务只能引用同会话任务；检测循环；按创建顺序启动依赖已成功的就绪任务。暂停任务会阻止自动取下一个任务，失败/取消的依赖保持阻塞。
- 多轨迹提炼要求至少三个已完成且全部动作验证成功的任务、至少两个会话、同应用/目标/环境/前置条件/步骤结构。变化的动作目录目标形成有限枚举参数；不生成任意 Provider 参数或放宽风险等级。
- 参数化技能不能走累积复核发布，必须对每个独立用例覆盖全部参数组合；最多 5 个参数、20 个组合。复用时再次校验绑定值和既有 Provider 动作目录。
- A/B 在同一独立环境中交替执行稳定版和候选版，每次重置用例，保存成功率、耗时、动作数和任务/检查点证据。A/B 不自动发布，也不代表生产成本实验。
- 发布版本最近 20 个独立任务观测至少 5 个且成功率低于 80% 时退回稳定旧版。SkillRunner 的单次失败立即回滚规则仍有效。
- 普通宿主会话在获得本会话已授权应用提示后召回受限 L3/L4；提示中明确要求受管任务观察并验证环境，不能直接作为可执行依据。
- 关键帧摘要保留时间、顺序、动作 ID 和证据引用，进入 L2 与时间线；原始像素不会注入上下文。TTL 同时清理摘要引用。

验证：`npm run check`（137 项自动测试、严格类型检查与构建）；`npm run benchmark`（1000 动作、100 请求、20 次重启、20 类不同模拟工作流）。已在临时目录安装锁定的 DSH 0.2.1-rc.5，真实宿主检查通过 14 项，包含受管模型调用只结算一次；报告见 host-smoke-report.json。

## Phase 3 扩展实现

- schema v6 新增向量索引、模型质量/费用反馈、子任务关系、祖先预算占用、同步收件箱及导出游标。所有迁移保留旧数据。
- `models.enabled` 显式启用受管模型执行，允许最多三次尝试，每次独立预留与结算；缺少 usage 的失败保留保守费用。任务业务完成后才记正向质量反馈。
- `models.review` 将结构化复盘绑定到宿主现有模型服务，仍受独立 10% 配额与每任务两次限制。`models.vision` 单独允许按需发送脱敏 ROI PNG，本地规则足够时不调用模型，重复帧回答复用缓存。
- 混合检索默认采用本地字符/词 n-gram 哈希向量和 FTS 结果融合，也可经 `knowledge.hybrid.index` / `knowledge.retrieve` 的向量参数接入外部语义向量。模型推断、归档、其他应用和过期记忆继续隔离。
- `sync` 采用命名空间绑定的 AES-256-GCM 包，密钥仅从环境读取。HTTPS GET/PUT 使用 ETag/If-Match 防止覆盖并发更新；保留所有版本冲突，远端资料必须经本机收件箱审核，并重新走记忆/技能候选流程。
- `telemetry` 输出标准 OTLP JSON 到显式配置的 Collector；只导出属性白名单，拒收或网络失败不会推进持久游标。
- 子任务按依赖图和并发上限执行；实际模型预留同时占用所有祖先预算。取消/暂停传播到后代，桌面仍共享单一互斥租约。
- 桌面适配器池只调度宿主当前激活槽位，不注册新 Provider，提供应用/窗口/权限验证。采集驱动、语义点击/无障碍树和 OS 权限仍由既有 Provider 提供。
- 视觉增加稳态窗口、自适应采样、ROI 原型分类、带时间与序号的合图、按需模型检查；内存帧有界，关闭即清理。
- 学习维护可选自动提炼候选、合并完全相同的可执行图并淘汰 30 天无证据候选。预测预算只在用户既定上限内缩减，不自动提额。
