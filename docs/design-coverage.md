# 设计逐项对照

更新：2026-11-13。基线：`IMe_插件开发设计说明书_v1.0.md` 与 `IME-技术架构图.png`。本表区分可运行实现、宿主提供的能力和效果验收，不把模拟成功等同于生产验收。

| 设计项 | 实现与入口 | 边界与验证 |
| --- | --- | --- |
| F-01 成本、余额、预算、预测 | 四级原子预留/结算、每次重试独立入账、未知账单对账、价格快照、多币种、HTTP 一次性预留凭据门禁与未发送释放；`CostGateway.forecast`、`adaptiveTaskBudget`、费用页 | 预测仅在用户上限内调整任务分配；真实余额依赖账户凭据。宿主流入口仍报告 hardLimit=false，不宣称任意 远端 Provider 自行额外计费或其他插件绕过的零超支 |
| F-02 桌面、恢复与多驱动 | `ToolDesktopPort`、`DesktopProviderPool`、单一激活槽位、应用/窗口/权限检查、跨进程租约、审批、取消 | 驱动与 OS 权限由现有 Provider 提供；目录中可使用语义目标或坐标，不解析未知工具格式，不自动重放不确定动作 |
| F-03 视觉采样、状态与多帧 | ROI/脱敏、变化过滤、稳态窗口、限频、自适应采样、ROI 均值原型分类、时间/序号合图、TTL、PNG/宿主附件解码；`ime_vision_inspect` | 本地分类足够时零模型请求；需要时发送脱敏 ROI PNG，必须同时启用 models.vision、支持视觉的路由与报价。未附带大型视觉网络或采集驱动 |
| F-04 记忆、冲突与混合检索 | 五种类型、候选信任、FTS、应用/TTL/冲突过滤、删除索引；`HybridSearch` 的向量结果融合；加密同步 | 默认向量为本地字符/词 n-gram 哈希特征，不冒充神经语义模型；支持外部 model/vector 索引与查询参数。同步知识重新进入候选审核 |
| F-05 技能生命周期与演化 | 稳定目标 ID、不可变签名、独立观测、有限参数提炼、全组合验证、A/B、发布/回滚、退化监控、依赖版本校验与失效传播、维护合并与淘汰 | 参数仅来自同环境同结构的已验证目录目标；自动维护不放宽权限或发布门槛；暂停、取消和正常审批等待不计作技能质量失败 |
| F-06 自审、配额与修订 | 规则复盘、模型复盘绑定、每任务两次、独立 10% 配额、结构化报告；复核发布/修订/A/B/回滚 | models.review 使用宿主现有 preparedCall，默认关闭；复盘只生成提案，不能执行生产修改。质量/成本反馈供路由与技能监控使用 |
| F-07 L1–L4、自适应配额与原生压缩 | 按层字符/Token 配额、宿主 Token Meter 估计、按模型剩余窗口收缩、L3/L4 按需召回、压缩摘要不变量检查与任务快照补回 | 真正压缩由宿主原生 Compaction 的自动策略承担，IMe 不注册第二套压缩器；未知容量不猜测；L1 放不下会明确拒绝 |
| F-08 三档与学习路由 | 模态/工具/窗口/币种/隐私/速率/预算过滤，持久化任务结果与费用统计，按成功概率和费用排序；`ime_model_route` / `ime_model_call` | 只有业务任务成功后才计正向质量反馈；普通会话当前模型仍由宿主掌握。已验证的模型调用入口在真实 DSH 中只结算一次 |
| F-09 队列、依赖与并行子任务 | 持久状态机、检查点、恢复核验、同会话 DAG、就绪队列；`ime_subtasks_create` / `ime_subtasks_run` | 子任务预留同时占用所有祖先预算，失败/未知账单不释放；父级暂停/取消传播，鼠标键盘仍串行 |
| F-10 安全与权限隔离 | 最小应用授权、窗口/权限状态检查、单次过期审批、敏感记录检测、帧脱敏、模型工具无控制面权限、同步待审区、命名空间与加密 | 同步不复制预算、凭据、授权或发布信任。插件与采集依赖宿主权限，生产 OS 授权由用户完成；不实现云端多租户管理平台 |
| F-11 时间线、对比与 OTel | SQLite/outbox、在线增量 JSONL 与轮转、费用/缓存/高消费失败步骤/预算告警/预测统计、A/B 证据、OTLP/HTTP 导出、持久化长任务验收与账单差异核对 | 导出属性采用白名单；远端拒收不推进游标；Collector 端到端运营可用性需目标部署实测 |

## 运行闭环与入口

观察：`ime_observe` / `ime_vision_inspect` → 检索：`ime_memory_search` / `ime_skill_search` → 路由：`ime_model_route` / `ime_model_call` → 执行：`ime_execute` / `ime_skill_run` / 子任务编排 → 逐步断言与检查点 → `ime_task_finish` → 候选、复盘与独立验证 → 发布复用。

新增控制台入口为「同步与扩展」；提供加密包导入/导出、云端交换、待审记录、OTLP 导出、技能维护、视觉合图和子任务执行。模型没有同步审核、发送遥测、修改策略或发布技能的工具。

## 当前验证

- `npm run check`：137 项测试、源码/测试/示例/基准类型检查及构建通过。
- `DSH_BIN=<隔离安装的 0.2.1-rc.5 CLI> npm run test:host`：14 项真实宿主检查通过；使用隔离测试 Provider，不访问生产桌面或付费模型。
- `npm run benchmark`：1000 动作/检查点、100 个混合请求、20 次重启；另有 20 类不同模拟 UI 状态机，探索与重启后技能复用均 20/20 成功。
- 报告：`host-smoke-report.json`、`benchmark-report.json`、`workflow-benchmark-report.json`。

## 外部验收条件

真实桌面长任务、目标 OS 权限/窗口兼容性、真实报价和账户实扣对账、Provider 内部重试与计费上界、生产模型摘要质量以及真实成本下降需要用户实际部署环境与授权凭据。代码不会为满足验收数字而默认启用付费模型或向未知远端上传资料。


## 剩余运行缺口的补全

- HTTP 文本模型入口直接绑定一次性预算预留凭据，在创建 socket 前消费；没有 SDK 隐式重试或重定向。发送前失败可释放预留，已进入传输或崩溃后的请求仍按未知费用保留。Provider 超界用量会触发路由熔断，普通宿主链路的 hardLimit 声明范围不扩大。
- 桌面观察可经 pngPath 或 attachmentPath 解码非交错 8-bit PNG，使用 CRC、尺寸及解压上界检查后再进入脱敏灰度管线。
- 技能依赖不仅持久化，还参与发布和逐动作派发校验；依赖库升级/回滚递归撤出消费者，跨设备导入会重新映射并审核版本引用。
- 验收页面与 `npm run acceptance` CLI 记录实际观察、检查点、资源和停止延迟；SQLite 保存中间进度，真实 SIGKILL 回归证明重启后保留 interrupted 报告。
- 历史任务 A/B 严格检查等量独立任务、应用/目标/环境、报价与币种，按全部费用/成功数比较；30% 阈值采用整数运算。账户实扣账单行独立保存并校验冲突，不改写历史报价和未知用量。

上述功能已通过 17 项新增回归，总计 137 项测试。目标部署的 60–120 分钟观测和账单实扣核对，仍需指定实际实例、任务与账单文件，不能从测试数据生成生产结论。
